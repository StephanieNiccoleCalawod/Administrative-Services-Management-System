# Administrative-Services-Management-System

## Technology Stack (Latest Versions)

- **Node.js**: v26.1.0+
- **NestJS**: v11.1.19+
- **Vite**: v8.0.11+
- **React**: v19.2.6+
- **PostgreSQL**: v18.3+

## Getting Started

### 1. Prerequisites
Ensure you have the following installed on your system:
- [Node.js v26.1.0](https://nodejs.org/)
- [PostgreSQL v18.3](https://www.postgresql.org/download/windows/)

### 2. Global Tooling
Install the NestJS CLI globally:
```bash
npm install -g @nestjs/cli
```

### 3. Installation
Run the following command in the root directory to install all dependencies for the monorepo:
```bash
npm install
```

### 4. Running the Application
- **Backend Services**: Navigate to `services/admin-system` and run `npm run start:dev`.
- **Frontend**: Navigate to `client/web-app` and run `npm run dev`.
